# 🇾🇪 دليل اليمن

> الدليل الشامل للأعمال والخدمات في جميع محافظات اليمن

## ✨ المميزات

- 📍 أكثر من 500 مكان مسجل
- 🏙️ 21 مدينة يمنية
- 🏷️ 12 تصنيف رئيسي
- 🔍 بحث ذكي ومتقدم
- ❤️ نظام المفضلة
- 📞 اتصال مباشر
- 💬 تكامل مع واتساب
- ➕ إضافة أماكن جديدة
- 🔔 إشعارات
- 📱 تصميم متجاوب
- 🌐 دعم RTL للعربية

## 🛠️ التقنيات

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript ES6+
- Font Awesome 6
- Google Fonts (Tajawal)
- LocalStorage

## 🚀 التشغيل

```bash
# فتح مباشر
open index.html

# خادم محلي
npx serve .
python3 -m http.server 8000
```
